# Lodolin

一个本地运行的摄影小站：作品集一屏一品照片墙（24 件实拍，按地区分类）+ 摄影设备页（ZV-E10 + 腾龙 17-70）；透明液态玻璃 UI + 流水转场 + 中式元素。

3D 星河场景（银河系 / 地球粒子模型）已抽成独立项目，见同级目录 `lodolin-3d/`。

## 如何运行

无需安装任何依赖，双击 `index.html` 即可在浏览器中打开。

- 作品集照片全部本地化在 `assets/photos/`，不依赖任何外链图床。
- 快速体验：直达页面 `#works`（作品集）、`#about`（介绍）、`#gear`（摄影设备）。
- 导航：longing / 摄影设备 / 作品集 三档（默认进 longing 首页），液态玻璃滑块跟随切换；点左侧「Lodolin」回首页（longing）；抖音主页入口放在「longing」介绍页的按钮里；作品集顶部有分类胶囊（全部 / 天体 / 美食 / 桂林 / 南宁 / 深圳 / 北海 / 崇左·扶绥）。
- 回到顶部：三个页面右下角固定一枚玻璃按钮（不随内容滚动），页面向下超过 240px 才出现，点击平滑回顶。

## 常见修改指南

- **改 3D 模型**：银河 / 地球粒子与舞台都在同级目录 `lodolin-3d/`（独立可运行，参数说明见其 readme）。
- **改主题色 / 玻璃质感**：`css/style.css` `:root` 的 `--accent`、`--glass`、`--glass-blur`。
- **换 / 加作品**：照片丢进 `assets/photos/`，再复制 `index.html` 里 `.work` 这一段改图名、标题、描述、meta；横构图加 `is-wide`、竖构图加 `is-tall`（`css/style.css` 里已有对应规则）。
- **改作品集开场文案**：`index.html` 的 `.works-head p`。

## 图片防保存

作品集与器材页的照片做了三层前端拦截，目的是提高"随手存图"的成本：

| 手段 | 位置 | 效果 |
| --- | --- | --- |
| `img { pointer-events: none }` | `css/style.css` 末段 | 指针命中的是外层容器而非 `<img>`，右键"存储图像"、移动端长按菜单都拿不到图片节点 |
| `.work-media::after` / `.gear-photo::after` 透明层 | 同上 | 即使 `pointer-events` 被覆盖，透明层仍挡住取图 |
| `contextmenu` / `dragstart` / `Ctrl+S` 拦截 | `js/app.js` 的 `initImageGuard()` | 右键、拖拽到桌面、保存网页统一阻止，并弹一次"照片受保护，不支持保存"提示 |

同时照片的悬停放大改由容器驱动（`.work-media:hover img`），所以加了遮罩后视觉动效不变。

**必须说明**：前端只能防住右键与长按，**防不住截图、录屏、开发者工具和网络请求**。真正要保护版权，靠图片上已有的 Lodolin 水印 + 低分辨率版本更实际。

## 已知边界

- 照片为 2026.11.24 两轮替换后的高画质版本（长边 1732~1920px、带 Lodolin 水印），75 张合计约 61.5MB（单张 0.3~1.5MB）；本地浏览无压力，若要上线建议先压到长边 1600px、质量 82。
- 图片 `src` 带 `?v=20261124b` 版本号用于刷新缓存，再换图时把它改成新的日期即可。
