# Lodolin的奇妙世界

一个本地运行的沉浸式星云小站：首页是 50000 粒子的银河系棒旋星系（写实还原），点击可切换显示地球（含地月系），拖动环视、滚轮缩放、鼠标掠过推开粒子；透明液态玻璃 UI + 流水转场 + 中式元素；附带摄影设备页与作品集一屏一品照片墙。

## 如何运行

无需安装任何依赖，双击 `index.html` 即可在浏览器中打开。

- Three.js 已下载到 `vendor/three.min.js`（r128），完全离线可用。
- 作品集照片全部本地化在 `assets/photos/`，不依赖任何外链图床。
- 快速体验：直达页面 `#works`（作品集）、`#camera`（星河）、`#gear`（摄影设备）。
- 星河页交互：拖动环视（转动银河），滚轮/双指缩放，鼠标掠过会推开粒子；**点击银河会先定位太阳系（本地臂上的发光标记），镜头飞越并放大到地球**；进入地球视角后拖动绕地球环视、滚轮缩放，月球沿轨道绕地公转；再点一下飞回银河。

## 天体形态细节

| 形态 | 还原的真实结构 |
| --- | --- |
| 银河系 SBbc | 细长棒（棒角 25°）+ 盒状/花生核球 + 四主臂自棒两端发出（英仙臂/盾牌-半人马臂/矩尺臂/人马臂，对数螺线 pitch≈18°）+ 本地臂刺（猎户-天鹅支臂，太阳所在）+ 薄盘年轻蓝白星（内暖外蓝径向梯度）+ 厚盘年老偏红星 + 沿臂 HII 粉斑与 OB 蓝协（含少量红超巨星团）+ 臂内缘尘埃带、核区尘埃环与中央分子环（3.5-5kpc）+ 外盘翘曲 + 球状星团晕 + Sgr A* 核心 |
| 地球（地月系） | 粒子化球体（Points，无外部资源）：真实大陆多边形轮廓（北美/南美/格陵兰/非洲/欧亚 + 岛屿 + 荒漠）+ 按纬度分层植被色 + 极地冰盖/北冰洋海冰，核心实心球用表面法线定向光做日/夜明暗；云层（加色白点沿纬度带）+ 大气辉光壳；地轴倾角 23.4° 与自转；附月球（月海/高地/环形山亮斑，潮汐锁定）沿约 5° 倾斜轨道面绕地公转，带轨道环 |

粒子特性：银河系桌面 50000 / 移动端 25000 自适应；每粒子独立闪烁相位（着色器驱动）；弹簧力归位 + 噪声漂移 + 鼠标斥力；背景尘埃常驻漂移。地球为粒子（核心 26000 + 云 5600 + 大气 3400 + 月球 4200），银河视角下缩成与粒子等大的小点，随拖动一起转动。

## 文件结构

```
lodolin-world/
├── index.html          入口页（星河 / 作品集 两视图）
├── css/style.css       全部样式（透明液态玻璃 + 流水转场 + 中式元素）
├── js/galaxy.js        银河系粒子生成（棒核 + 四主臂 + 薄/厚盘 + 尘埃 + 晕）
├── js/earth.js         地球粒子球（海洋/大陆/冰盖/云层/大气，日夜间明暗，自转）
├── js/morph.js         银河系 ⇄ 地球 切换引擎（弹簧归位 + 噪声漂移 + 鼠标斥力 + 闪烁）
├── js/stage.js         三维舞台：拖拽/缩放/鼠标斥力 + 银河⇄地球飞越过渡 + 太阳标记
├── js/app.js           双视图路由 + 作品集入场动画
├── js/particles.js     （历史遗留）早期粒子生成，当前未引用
├── js/camera3d.js      （历史遗留）装配态相机建模，当前未引用
├── assets/photos/      作品集实拍照片（24 张，本地化）
├── assets/gear/        摄影设备页器材图（ZV-E10 + 腾龙 17-70 挂机形态）
└── vendor/three.min.js Three.js r128（本地，离线可用）
```

## 常见修改指南

- **改粒子数量**：`js/morph.js` 顶部 `N = isMobile ? 25000 : 50000`（银河系）；地球各层在 `js/earth.js` 的 `build()` 里（核心 26000 / 云 5600 / 大气 3400 / 月球 4200）。
- **改闪烁强度**：`js/morph.js` vertexShader 里 `0.72 + 0.28 * sin(...)` 的两个系数。
- **改形态细节**：`js/galaxy.js`（棒/核球/四主臂/双盘/尘埃/晕各分支比例与颜色），每个分支都有注释标明对应真实天体结构。
- **改主题色 / 玻璃质感**：`css/style.css` `:root` 的 `--accent`、`--glass`、`--glass-blur`。
- **换 / 加作品**：照片丢进 `assets/photos/`，再复制 `index.html` 里 `.work` 这一段改图名、标题、描述、meta；横构图加 `is-wide`、竖构图加 `is-tall`（`css/style.css` 里已有对应规则）。
- **改作品集开场文案**：`index.html` 的 `.works-head p`。
